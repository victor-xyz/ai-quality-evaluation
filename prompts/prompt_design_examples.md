# Prompt Design Examples

These prompts are designed to test different AI quality dimensions.

## Grounding Test

> Answer using only the information supplied in the scenario. If the information is insufficient, identify what is missing rather than inventing an answer.

**Tests:** factual grounding and hallucination resistance.

## Instruction-Following Test

> Produce the requested answer while satisfying every explicit formatting constraint. Before finalising, check that the required format, length, language, and scope have been followed.

**Tests:** instruction following and constraint adherence.

## Ambiguity Test

> Identify ambiguity in the user's request before answering. If multiple interpretations are plausible, state the interpretation you are using and what additional information would resolve the ambiguity.

**Tests:** ambiguity detection and reasoning.

## Context Integration Test

> Use all relevant information provided in the conversation. Do not ignore constraints or preferences that materially affect the requested output.

**Tests:** context integration.

## Error-Detection Test

> Review the response below for factual errors, unsupported claims, missing requirements, contradictions, and irrelevant content. For every issue, identify the evidence, classify the error, and explain its impact.

**Tests:** analytical evaluation and error classification.
